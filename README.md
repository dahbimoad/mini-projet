# Gestion Scolaire

> **Mini-projet académique** - Une application simple de gestion scolaire pour démontrer Spring Boot + Thymeleaf + MySQL.  
> Pour des projets professionnels complets, visitez [dahbimoad.com](https://dahbimoad.com)

## Demo

🌐 **Live:** [mini-projet.dahbimoad.com](http://mini-projet.dahbimoad.com)

## Stack

- Spring Boot 3
- Thymeleaf
- MySQL / MariaDB
- Docker

## Démarrage

```bash
# 1. Cloner le projet
git clone https://github.com/dahbimoad/mini-projet.git
cd mini-projet

# 2. Créer le fichier .env
cp .env.example .env

# 3. Lancer l'application
docker-compose up -d
```

Accéder à : http://localhost:8080
